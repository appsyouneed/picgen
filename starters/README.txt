STARTER IMAGES
==============

Place up to 10 reference photos here for quick one-click loading in the Picgen tab.

File names must be:
  start1.jpg   (or start1.png or start1.webp)
  start2.jpg
  start3.png
  start4.webp
  start5.jpg
  ...
  start10.jpg

Supported formats: .jpg, .png, .webp (one file per slot)

How it works:
- Each file corresponds to a numbered button (1-10) in the Photo Editor tab
- Clicking a button instantly loads that image as input — no browsing or uploading needed
- Great for keeping your most-used subjects (yourself, a partner, a character) one click away

Rules:
- Must be .jpg, .png, or .webp format
- Any resolution works (automatically resized by the pipeline)
- You can use any number of the 10 slots — missing files are simply ignored
- Replace any time — changes take effect on next app restart
